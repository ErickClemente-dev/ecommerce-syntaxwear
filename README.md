# SyntaxWear

## Sobre o projeto

O **SyntaxWear** é uma landing page de e-commerce dedicada à venda de tênis e sneakers. A página foi desenvolvida com HTML e CSS para apresentar o catálogo da marca, destacar produtos principais e oferecer uma navegação visualmente organizada.

## Objetivo

Mostrar o estilo da marca, organizar os produtos em categorias e criar uma interface moderna e responsiva para o público da loja.

## Estrutura do projeto

- **index.html**: estrutura principal da página inicial.
- **css/**: arquivos de estilo organizados em componentes.
  - `base.css` — estilos base da página.
  - `reset.css` — reset padrão dos navegadores.
  - `variables.css` — variáveis de cores, fontes e espaçamentos.
  - `components/` — estilos separados para header, hero, cards, grid e footer.
- **images/**: imagens da marca, banners, ícones, logotipo e produtos.

## Seções presentes

- Cabeçalho com navegação e ícones de usuário/carrinho.
- Seção hero com chamada principal e botões de ação.
- Cards de categorias de tênis.
- Grade de produtos com destaque visual.
- Rodapé com newsletter, redes sociais e menus de navegação.

## Tecnologias utilizadas

- HTML5
- CSS3
- Imagens SVG, JPG e PNG

## Como visualizar

Abra a url: `https://erickclemente-dev.github.io/ecommerce-syntaxwear/` em um navegador.

## Observação

Este projeto é um exemplo estático de loja online, sem integração com backend ou sistema de pagamento.
